## Entry

`main.py` deterministically writes one one-line epitaph (famous last words)
to `/output/entry.txt`:

> Turns out 'I'll sleep when I'm dead' was a terrible retirement plan.

68 characters, one line, no stage directions, no explanation — a genuine
joke built on a twist of the old "I'll sleep when I'm dead" boast.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt`. Running it twice produces byte-identical output.
